# Super Spanish — Realidades 1, Capítulo 2A

Unidad interactiva para practicar **Tu día en la escuela**.

## Uso

Abre `index.html` en un navegador moderno. No requiere instalación.

## Publicar en GitHub Pages

1. Crea un repositorio público llamado `Realidades-1-Capitulo-2A`.
2. Sube `index.html` y `README.md` a la rama `main`.
3. Ve a **Settings → Pages → Build and deployment** y elige **Deploy from a branch**, `main`, `/ (root)`.
4. Cuando GitHub termine de publicar, la URL prevista es `https://SpanishwithPaula.github.io/Realidades-1-Capitulo-2A/`.

Material de práctica complementario elaborado a partir de los temas del capítulo 2A de Realidades 1. No es una publicación oficial de Pearson.
